# 课件捕手

面向教室大屏的绿色课堂记录工具：老师上课时它安静地待在托盘里，自动保存课件画面和原课件；下课后整理成一份带老师字迹的 PDF 笔记。

整个程序只有一个 `课件捕手.exe`（约 108 KB），不需要安装、不需要联网、不需要 Office 以外的运行库，适合在机房和教室电脑上使用。

## 它解决什么问题

一堂课结束后，学生手里通常只有一份 PPT，缺两样东西：

1. 老师上课时在课件上写的字、画的图；
2. 讲到某一页时的完整画面。

课件捕手把这两样都留下来，并按时间整理好：

```
保存目录\数学\2026-11-07\1030_函数的单调性\
    课件原文件.pptx      老师上课用的原课件副本
    课堂笔记.pdf         按时间抽取的关键画面，带字迹，可打印
    课堂信息.txt         时间、科目、源课件、页数、收尾原因
    截图\                PDF 关闭时保存的原始截图
```

## 主要功能

- **自动识别课堂**：监听 PowerPoint、WPS 演示、希沃白板 5、鸿合白板等进程，检测到演示窗口就自动开始记录。
- **安静记录**：默认每 1.5 秒截一张前台演示窗口，画面没变化时自动跳过，一节课通常只有几十到一百多张图。
- **自动分科归档**：按进程名、窗口标题和课件文件名里的关键词判断科目（可自定义），保存到 `科目\日期\时间_标题\`。
- **带字迹的 PDF**：用内置的轻量 PDF 写入器把关键画面串成 PDF，每页停留时间与课堂时间轴对应，可用阅读器直接翻看、打印。
- **原课件留档**：通过 PowerPoint COM 或文件搜索找到源 `.pptx/.ppt`，复制一份到课堂文件夹；找不到时在 `课堂信息.txt` 里说明。
- **自动收尾**：演示程序退出、窗口关闭、切到其他窗口超过 15 分钟、或键鼠空闲超过 5 分钟时，自动结束并保存；程序退出/关机时也会先保存。
- **托盘常驻**：单实例运行，可暂停/继续，可设置开机自启，可在托盘直接打开课件文件夹和最近一节课。
- **兼容性优先**：COM 取页码失败时仍可正常截图；没有 PowerPoint 也能记录白板；配置和日志都在程序目录，方便拷走。

## 目录结构

```
仓库\
  src\                    源码（C# / WinForms）
  resources\              程序图标
  build.ps1               构建脚本
  README.md               本文件
  使用说明.md
  更新日志.md
  dist\                   构建输出，不提交；发布包里就是运行目录
```

运行时会在 exe 同目录生成 `配置.xml`、`日志\`、`临时\`、`课件\`。

## 构建

在 Windows 上用系统自带的 .NET Framework 4 编译器即可，不需要 Visual Studio：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

生成 `dist\课件捕手.exe`。构建脚本会调用 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`，并把 `src\*.cs` 编译成一个 WinForms 可执行文件。

## 使用

1. 把 `课件捕手.exe` 放到 D 盘或其他空间充足的文件夹。
2. 双击运行，会弹出“课件捕手已在运行”小窗口；点“隐藏到托盘”收起。托盘出现图标即表示已在监听。
3. 老师打开 PPT/WPS/白板讲课后，程序会自动开始记录；下课后自动保存。
4. 右键托盘图标 → “打开课件文件夹”，按科目和日期找到这节课。
5. 以后想确认程序是否在运行，再双击一次程序，就会把状态窗口叫出来。

详细说明见 [使用说明.md](使用说明.md)。

## 隐私

- 所有课件、截图、PDF 都只保存在本机 `保存目录`，程序不上传任何内容。
- 不包含录音、麦克风或语音识别功能。

## 已知限制

- 只记录前台演示窗口；老师切到浏览器放视频时，那段时间不会录进课件。
- 画面去重基于图像指纹，快速翻页时可能合并掉极短的过渡页。
- PDF 里的每一页是位图而不是可选中文字；需要文字版请用原课件。
