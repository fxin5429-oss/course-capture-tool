# 课件捕手

> 把老师上课时的课件画面和手写批注，整理成一份能打印、能回看的 PDF 笔记。

课件捕手是面向教室大屏的绿色小工具。上课前双击运行，它安静地待在托盘里；老师打开 PPT、WPS 或白板讲课时自动开始记录，下课后把关键画面按时间整理成 PDF，并把原课件复制到同一个文件夹。

整个程序只有一个 `课件捕手.exe`（约 108 KB）。不需要安装、不需要联网、不需要管理员权限，也不依赖 Office；有 PowerPoint 时能自动读取页码和源文件，没有也能正常截图。

## 它解决什么问题

一堂课结束后，学生手里通常只有一份 PPT，缺两样东西：

1. 老师讲课时在屏幕上写的字、画的图；
2. 讲到某一页时的完整画面。

录屏能保留，但文件大、回看慢；拍照又来不及。课件捕手只截演示窗口，按画面变化去重，最后生成一份几十页的 PDF——翻看、打印、发给学生都比视频轻便。

## 主要功能

**记录**

- **自动识别课堂**：监听 PowerPoint、WPS 演示、希沃白板 5、鸿合白板等进程，检测到演示窗口就自动开始。
- **安静截图**：默认每 1.5 秒截一张前台演示窗口，画面没变化时自动跳过；一节课通常只有几十到一百多张图。
- **自动收尾**：演示程序退出、窗口关闭、切到其他窗口超过 15 分钟、或键鼠空闲超过 5 分钟时自动结束并保存；正常退出程序时也会先保存。
- **原课件留档**：通过 PowerPoint COM 或文件搜索找到源 `.pptx/.ppt`，复制一份到课堂文件夹；找不到时在 `课堂信息.txt` 里说明。

**整理**

- **带字迹的 PDF**：用内置的轻量 PDF 写入器把关键画面串成 PDF，每页停留时间与课堂时间轴对应，可用任意阅读器翻看、打印。
- **自动分科归档**：按进程名、窗口标题和课件文件名里的关键词判断科目（可自定义），保存到 `科目\日期\时间_标题\`。
- **失败兜底**：PDF 生成失败或关闭 PDF 时，原始截图会按时间顺序留在 `截图\` 里，不会丢内容。

**使用**

- **托盘常驻**：单实例运行，可暂停/继续记录，可设置开机自启，可在托盘直接打开课件文件夹和最近一节课。
- **看得见的状态**：再双击一次程序会打开状态窗口，显示当前是否在记录；即使托盘图标被 Windows 收进 `^`，也能从这里操作。
- **兼容性优先**：COM 取页码失败时仍可正常截图；没有 PowerPoint 也能记录白板；配置和日志都在程序目录，方便整个文件夹拷走。

## 快速开始

1. 下载 Release 里的 zip，解压到 D 盘或其他有写权限的目录；不要放在 `Program Files` 或只读共享盘。
2. 双击 `课件捕手.exe`，会弹出“课件捕手已在运行”小窗口；点“隐藏到托盘”收起。托盘出现图标即表示正在监听。
3. 老师打开 PPT / WPS / 白板讲课后，程序自动开始记录；下课后自动保存。
4. 右键托盘图标 →“打开课件文件夹”，按科目和日期找到这节课。
5. 以后想确认程序是否在运行，再双击一次程序，就会把状态窗口叫出来。

详细步骤和常见问题见 [使用说明.md](使用说明.md)。

## 一节课的文件

```
保存目录\数学\2026-11-07\1030_函数的单调性\
    课件原文件.pptx          老师上课用的原课件副本
    课堂笔记.pdf             按时间抽取的关键画面，带字迹，可打印
    课堂信息.txt             时间、科目、源课件、页数、收尾原因
    课件原文件_未找到.txt    找不到源课件时才有
    截图\                    PDF 未生成时才有（失败或关闭 PDF），按时间保存原始截图
```

## 构建

在 Windows 上用系统自带的 .NET Framework 4 编译器即可，不需要 Visual Studio：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

生成 `dist\课件捕手.exe`。构建脚本会调用 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`，把 `src\*.cs` 编译成一个 WinForms 可执行文件。

## 隐私

- 课件、截图、PDF 只保存在本机 `保存目录`，程序不上传任何内容。
- 不包含录音、麦克风或语音识别功能，不联网、不登录、不统计。
- 课件画面里可能包含学生姓名、班级等信息，发给别人前请先确认。

## 已知限制

- 只记录前台演示窗口；老师切到浏览器放视频时，那段时间不会录进课件。
- 画面去重基于图像指纹，快速翻页时可能合并掉极短的过渡页。
- PDF 里的每一页是位图，不是可选中文字；需要文字版请用原课件。
- 没有 PowerPoint 时无法自动读取页码和源文件，但截图和 PDF 仍可正常生成。
